## Description

The Kid-Friendly Calculator is a web-based application designed for elementary school students (grades K–6) to practice basic arithmetic skills.
The calculator provides a colorful, interactive, and easy-to-use interface that allows students to perform addition, subtraction, multiplication, and division. It also includes features such as a calculation history, sound effects, animations, and a guided display to help students understand what type of math they are doing.

## Instructions to Run the App

### File Explorer
1. Open the project folder in file explorer
2. Locate `index.html`
3. Double-click the file
4. It will open automatically in your default web browser

### VS Code
1. Open the project folder in VS Code
2. Open `index.html`
3. Hold Shift+Ctrl+D (Shift+Cmd+D for Mac)
4. Click `Run and Debug`
5. Choose desired web browser
6. It will open in your selected web browser

### Terminal
1. Open your terminal
2. Open `bash`
3. Navigate to the project folder
```bash
cd path/to/project
```
4. Open the app in your browser
* Mac:
```bash
open index.html
```
* Windows:
```bash
start index.html
```

## Usage

1. Launch the application
2. Click "Start Calculator" on the opening screen
3. Use the buttons to enter numbers and operations
4. Press "=" to calculate the result
5. View:
  * The full expression
  * The answer
  * The operation type (e.g., Addition, Division)
6. Use:
  * ⌫ to remove last character typed
  * C / Clear Current to reset the current expression
  * Clear History to remove past calculations

---

## Features

* Clickable/tappable calculator interface
* Supports addition, subtraction, multiplication, and division
* Parentheses support for grouped expressions
* Real-time operation display (e.g., "Addition and Multiplication")
* Displays full expression and answer
* Keeps history of last 5 calculations
* Clear current calculation
* Clear history
* Confetti animation when equals is pressed
* Sound effect on calculation
* Kid-friendly design and font
* Opening screen with animated typing effect

---

## Additional Notes

This application was designed to be engaging and accessible for younger users by combining visual feedback (confetti), audio feedback (sound effects), and simple navigation.
