## Description

This is a simple calculator that you can use to add, subtract, multiply, and divide. The user will be prompted to enter one of the operations, then asked to enter the numbers as needed. 

---

## Instructions to Run the App
First, run the app. You will be prompted to enter a number that chooses if you want to add, subtract, multiply, and divide. Pick the number that corresponds to the right operation that you want to do. When you pick an operation, enter the numbers you would like to perform that operation. Press enter and your answer will be shown. The program will run until you exit.

### VS Code
1. Open the project folder in VS Code
2. Open `calculator.py`
3. Then press and hold fn then press F5 to run the code

### Terminal

1. Open the project folder
2. Navigate to the project directory
3. Run the code by holding down fn on the keyboard then pressing f5

---

## Usage

1. Run the app
2. When prompted, enter a number for the operation you wish to run (1 - 4) or 5 if you want to quit
3. When prompted again enter the numbers as asked

---

## Features

* Addition - adds 2 values that are entered
* Subtraction - subtracts 2 values that are entered
* Mulitiplication - mulitplies the 2 numbers that are entered
* Division - divides the 2 numbers that are entered
