# 🧮 Programming Utilities

A collection of calculator and unit conversion projects
developed during my Associate of Applied Science in
Computer Programming at Houston Community College (HCC).

These projects explore foundational programming concepts
through practical applications developed using Python
and web programming technologies.

## 📂 Projects

### 🐍 Python Calculator
A calculator application developed using Python to
perform mathematical operations.

### 🔄 Python Unit Converter
A Python application designed to convert between
different units of measurement.

### 🌈 Kid-Friendly Calculator
A web-based calculator project designed with a
child-friendly interface.

### 🌐 Web Unit Converter
A unit conversion application developed using
web programming technologies.

### Python Applications
1. Navigate to the appropriate project folder.
2. Open the Python file in your preferred IDE.
3. Run the application using Python 3.

### Web Applications
1. Navigate to the appropriate project folder.
2. Locate the main HTML file.
3. Open the HTML file in a web browser.
